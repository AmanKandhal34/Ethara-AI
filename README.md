🚀 TaskFlow

A simple full-stack Project & Task Management System built using React, Node.js, Express, and SQLite.

It allows users to create projects, manage tasks, and track progress in a clean and minimal dashboard.


link=https://ethara-ai-theta.vercel.app/login

⚙️ Tech Stack

Frontend:

React (Vite)
Tailwind CSS
Axios

Backend:

Node.js
Express.js
SQLite
JWT Authentication
✨ Features
User Authentication (Login / Register)
Create & manage projects
Add, edit, delete tasks
Task status tracking (Todo, In Progress, Done)
Dashboard with basic analytics
Search & filter tasks
Responsive UI
🗄️ Database

SQLite is used with relational tables:

Users
Projects
Tasks
